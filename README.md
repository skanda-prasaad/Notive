# Notive: Your Personal Knowledge Hub 📚✨

Notive is a modern web application designed to help you capture, organize, and share your digital knowledge in one place. Think of it as a **centralized hub** for your ideas, bookmarks, and resources — seamlessly integrating content from YouTube, Twitter, Instagram, LinkedIn, Notion, and more.

🔗 **Live Demo:** [notive-azure.vercel.app](https://notive-azure.vercel.app)  
👨‍💻 **Author:** [skanda-prasaad](https://github.com/skanda-prasaad)  

---

## 🌟 Features

- **🔐 User Authentication** — Secure sign-up, sign-in, and sign-out with JWT.  
- **📝 Content Management** — Create, read, update, and delete notes & links.  
- **📂 Smart Organization** — Stay productive with the **P.A.R.A. Method** (Projects, Areas, Resources, Archives).  
- **🔗 Shareable Links** — Easily share content with public links.  
- **🚀 Live Deployment** — [View the app here](https://notive-azure.vercel.app).  

---

## 🛠️ Tech Stack

### Frontend
- ⚛️ **React + TypeScript** — Core of the app  
- ⚡ **Vite** — Lightning-fast bundler  
- 🎨 **Tailwind CSS** — Modern utility-first styling  
- 🧭 **React Router** — Smooth navigation  
- 🎭 **Lucide / React Icons** — Clean iconography  

### Backend
- 🟩 **Node.js + Express.js** — Scalable server  
- 📜 **TypeScript** — Strongly-typed backend  
- 🍃 **MongoDB + Mongoose** — Flexible NoSQL database  
- 🔑 **JWT Authentication** — Secure user sessions
